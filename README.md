# Goulash.tech для цветочных магазинов

Концепт-лендинг (тестовое задание): «Гуляш» для цветочных магазинов с доставкой.

- `npm install` — зависимости
- `npm run dev` — локальный сервер Vite
- `npm run build` — сборка в `dist/`

Деплой на GitHub Pages: `npm run deploy` (собирает и публикует `dist/` в ветку `gh-pages`).

Структура: `index.html`, `css/styles.css`, `js/app.js`, статика (видео, favicon) — в `public/assets/`.
Исходные клипы ролика (`assets/video/raw/`) в репозиторий не попадают.
